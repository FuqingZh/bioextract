# bioextract Tree-Review Remediation Implementation Plan

Version: v1.0
Date: 2026-08-26
Status: active implementation plan; not runtime authority

Applies to:
[bioextract tree review](../architecture/20260826-v1.0-bioextract-tree-review.md)

Reviewed commit: `64a88027159b0267bd2db72aa8c43a9f9838f226`

## Goal

Close the honesty and identity defects in the public contract, then the
domain-correctness gaps, without adding resources, downloaders, or analysis
policy.

This plan records delivery order. It is not runtime authority. The
[Domain Access Architecture](../architecture/20260729-v1.0-domain-access-architecture.md)
and [Materialized Dataset Contract](../architecture/tidy-dataset-contract.md)
remain authoritative until a later versioned successor updates them.

## Authority And Compatibility Baseline

- Repository guidance: `AGENTS.md`.
- Documentation map: `docs/README.md`.
- Test policy: `docs/testing/README.md`.
- Delivery: `docs/runbooks/repository-delivery.md`.

The tree review is observational. It does not enter the architecture authority
map as a current contract.

A successor that changes public API, publication schema, or README examples
must update the owning contract and tests together. Formal CephFS replacement
and package-tag publication remain separately authorized release actions.

## Non-Goals

This plan does not authorize:

- publishing to CephFS or deleting a prior formal artifact;
- adding a resource, generic query facade, or enrichment statistic;
- a v1 metadata compatibility reader;
- depending on `biofetch`;
- treating Reactome v0.5 / `20260817-r1` remaining release gates as passed.

## Delivery Units

Units are serial unless a later unit states that it may overlap.

### Unit 0 — Public contract truth

1. Rewrite `README.md` and `README.zh-CN.md` so metadata v2 and noun selection
   terminals (`compounds()`, `ancestors()`, `mappings()`, `scan_mapping()`,
   `unmatched_ids()`, …) are the taught API. Remove `extract_*` / `read_mapping`
   examples.
2. State one current package version in `pyproject.toml` that matches the
   intended development identity, or document that the tree is `0.1.0` until
   `scripts/sync_release_version.py` runs at tag time. Do not leave `dist/`,
   freeze TOML, and plans implying different current versions without labeling
   them historical.
3. Fail `write_duckdb` when `importlib.metadata.version("bioextract")` is
   unavailable, or write a distinct unresolved provenance key that cannot be
   read as a release.
4. Mark the inspection-plan metadata-v1 summary and `go-kegg-tidy.md`
   metadata-v1 provenance sentences as historical; current writers are v2-only.

Validation: contract API and publication tests, plus README examples that
import. Documentation-only slices do not require a CephFS smoke.

### Unit 1 — Domain correctness

1. UniProt knowledgebase and idmapping selections use `normalize_input_id` for
   `namespace="uniprot"`.
2. Directory constructors bound traversal (suffix allow-list, max depth,
   result-count cap). GO `.obo` matching uses suffix or an explicit name, not
   substring.
3. GO dangling parent/child edges raise `IntegrityError` before publication.
4. KEGG `from_duckdb` handles pin filesystem identity like GO/Reactome/ChEBI.
5. Reactome NCBI identifiers canonicalize or reject, consistent with ChEBI in
   the same helper.

Validation: focused unit/contract/integration tests for UniProt pipe IDs, GO
dangling edges, KEGG publication replacement, and bounded discovery. Then
`pdm run check` for this public-contract and cross-resource behavior.

### Unit 2 — Contract hygiene

1. Choose one GO name set for tidy frames and DuckDB tables, or document the
   remap as a first-class contract in `go-kegg-tidy.md`.
2. STRING and OmniPath errors say snapshot/source, not publication.
3. `TidyDataset` requires `resource_name`; `build_id_prefix` never fills it.
4. Document that source-backed GO ancestor queries materialize the selected
   closure, or implement ID-scoped projection so the `LazyFrame` claim holds.

Validation: resource contract tests and docstring examples.

### Unit 3 — Tests for the paths above

Add the missing fixtures named in the review: UniProt pipe IDs, GO dangling
parent, KEGG file replacement while a handle is live, directory discovery
overflow. Do not promote smoke tests into the default gate.

## Stop Rules

- Do not start a new resource adapter while Unit 0 is open.
- Do not add a metadata-v1 reader to make the current README true; change the
  README.
- Do not treat `"unknown"` package versions in existing DuckDB files as
  scientific identity.

## Validation Gate

Each unit ends with the smallest owning tests. Public API, publication schema,
or README contract changes run `pdm run check`. Formal snapshot delivery
remains a separately scoped release action.
