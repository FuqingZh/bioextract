# Cross-resource execution convergence: bounded P5 candidate evidence

Date: 2026-08-14
Status: repository and bounded gate complete; release-scale acceptance pending
compatible metadata-v2 publications

## What was measured

The public lazy-relation harness ran the same 12 cases as the frozen baseline:
idmapping narrow/wide, Rhea matches/bundle, UniProtKB proteins/bundle, ChEBI
matches/bundle, and KEGG matches/narrow/wide/bundle. It used one warmup and
five measured repetitions, the rat taxon `10116`, four fixed UniProt IDs, and
the fixed KEGG compound input. Every candidate relation schema, row count, and
semantic output hash matched the baseline.

The candidate used exact copies of the available five DuckDB publications in
`/tmp`. The copied `_bioextract` metadata was repaired only enough to satisfy
the current v2 reader (`metadata_schema_version=2`, no `bioextract.sources`,
and nullable `source_file.bytes`). No formal resource tree or CephFS artifact
was changed.

The result is therefore bounded algorithmic evidence, not a release benchmark.
The candidate environment also reports bioextract `0.1.0` and Polars `1.40.1`,
whereas the frozen baseline reports bioextract `0.4.0` and Polars `1.43.2`.
Those dependency and package-version differences prevent a production-scale
speedup claim even though output hashes reconciled.

## Release-scale blocker and decision

The official publications used by the joint_omics 23,362-feature workload are
metadata-v1 artifacts. Current bioextract correctly rejects them with
`IntegrityError: Unsupported UniProt metadata schema version`; accepting v1
again would violate the independent metadata-v2 migration contract. A custom
catalog pointing at the repaired `/tmp` copies would not be the frozen
publication-identity comparison and would turn this record into a synthetic
end-to-end result.

The P5 repository gate is therefore accepted for implementation correctness,
cleanup, and bounded physical observations. A later temporary v2-compatible
joint_omics experiment is recorded in the
[qualified cross-project record](20260814-v1.0-cross-resource-p5-v2-compatible-joint-omics.md):
its initial candidate reduced CPU/RSS but regressed wall time, and the P5a
Rhea-anchor follow-up then recovered wall time on the same bounded scope. The
follow-up is still not a formal release benchmark. Formal publication and
downstream contract acceptance require separately authorized v2 artifacts. No
package release, formal publication replacement, or `manifest.lock`/biofetch
dependency is implied.

The fixed KEGG 1,000-organism native publication and reverse-lookup evidence
remain valid as the development gate. The reverse lookup reconciled checksums
for 1, 100, and 4,718 actual inputs in the available `aaa` organism scope; it
does not replace the full-source or compatible joint_omics gate.
